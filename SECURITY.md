# Security

**Alpha: do not rely on this project to protect production.** The command filter is not an OS sandbox and does not restrict agents, MCP, scripts or other shells. Read [the threat model](docs/THREAT_MODEL.md) before use.

Please report vulnerabilities privately using GitHub's “Report a vulnerability” feature when it is enabled on the repository. If it is unavailable, contact the maintainers privately through their GitHub profiles; do not publish exploit details before maintainers can respond. Only the current development version is supported. Releases are not signed yet.
